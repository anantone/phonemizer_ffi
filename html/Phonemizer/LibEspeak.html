    Sentinel inter-phone separator requested from espeak (encoded in bits 8-23 of phonememode). \x01 never appears in IPA output, so substituting it afterwards with the user’s phone_sep cannot collide, whatever the phone_sep is (multi-character, spaces, even “-”).

def init!
  return true if @initialized
  rate = espeak_Initialize(AUDIO_OUTPUT_SYNCHRONOUS, 0, nil,
                           INITIALIZE_DONT_EXIT)
  if rate == EE_INTERNAL_ERROR
    raise "espeak_Initialize failed: is espeak-ng-data installed?"
  end
  @initialized = true
end

    espeak_Initialize must run once before anything else. Idempotent. AUDIO_OUTPUT_SYNCHRONOUS: no audio device is touched; DONT_EXIT turns a missing espeak-ng-data into a return error instead of a brutal exit().

def phonememode(phone_sep)
  mode = PHONEME_IPA
  mode |= (SEP_CHAR.ord << 8) unless phone_sep.empty?
  mode
end

    espeak-ng phoneme output mode flags: always IPA; in separator mode the sentinel character is OR-ed into bits 8+ (the phonemize pipeline substitutes the user’s separator for the sentinel afterwards). @param phone_sep [String] user phoneme separator (“” for none) @return [Integer] espeak-ng phonememode flags
